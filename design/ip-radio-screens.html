08

Ждущий режим

21:47
26 августа, среда
играет: RETRO FM

Через три минуты без действий: часы во весь экран, яркость приглушена. Внизу мелко — что продолжает играть.

Что здесь проверяется по ТЗ

  • Время слева вверху мелким шрифтом на всех рабочих экранах, не перекрывая название станции.
  • Крупный шрифт названия — требование по читаемости для пожилого пользователя, а не оформление.
  • Банк пресетов общий на оба режима, тип хранится в самой ячейке. Нажатие ячейки другого типа само переключает прибор — экран 04 показывает этот переход.
  • Полоса подсказок внизу на каждом экране: любой сценарий проходится физическими органами, без касания экрана.
  • Два эфирных диапазона, а не один. На экране подписаны коротко — «УКВ» и «FM»; OIRT и CCIR остаются в документации, пользователю они ничего не говорят.
  • Режим читается цветом раньше, чем прочитан текст: по бейджу справа вверху, по подсветке пресета, по цвету частоты.
