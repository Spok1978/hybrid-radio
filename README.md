# IP-Radio — приёмник УКВ/FM + интернет-радио

Проект приёмника с двумя режимами работы:

1. **Эфир** — УКВ OIRT (65,8–74 МГц) и FM CCIR (87,5–108 МГц): автопоиск,
   частота и название станции на экране, ручная настройка, пресеты.
2. **Интернет-радио** — подключение к Wi-Fi, поиск станций, воспроизведение,
   свой список станций.

Один цветной экран на оба режима, экранное меню + кнопки и энкодеры, один
громкоговоритель, переключение режимов программное — пресетом, кнопкой MODE
или через меню ([22](docs/22-mode-switching.md)).

## Статус

**Прошивка написана и работает на плате.** Интернет-радио играет со звуком,
экран и касание живые, Wi-Fi подключается, станции ищутся в каталоге
radio-browser и сохраняются на карту. Идёт отладка на Waveshare
ESP32-P4-WIFI6-Touch-LCD-5.

Оговорки, важные для понимания статуса:

* Звук временно идёт в **штатный кодек платы ES8311**, а не в целевой
  PCM5102A с усилителем TPA3118: своя обвязка ещё не подключена.
  Переключается ключом `IPRADIO_USE_BOARD_CODEC` в `firmware/main/board_pins.h`.
* **Внешней обвязки нет вовсе** — ни тюнера RDA5807M, ни кнопок,
  ни энкодеров. Поэтому всё управление продублировано касанием.
  Эфирный режим в коде есть, но проверить его нечем.
* УКВ OIRT отключён решением заказчика, `IPRADIO_ENABLE_OIRT 0`.

Что именно сделано и что осталось — [firmware/README.md](firmware/README.md).

**2026-08-26 — основная сборка перенесена на ESP32-P4** (плата Waveshare
ESP32-P4-WIFI6-Touch-LCD-5), список станций хранится в штатном формате
её прошивки. Разбор переноса, что переезжает без изменений и что открылось
заново — [docs/24-main-build-p4.md](docs/24-main-build-p4.md). Таблица решений
и схема ниже — для сборки на ESP32-P4. Ранняя ревизия на Raspberry Pi
отменена; её документы помечены в шапке «НЕАКТУАЛЬНО» и для сборки не
применяются (в таблице ниже — с пометкой).

Открытые вопросы — в [docs/06-open-questions.md](docs/06-open-questions.md),
сейчас их четыре: Q7, Q8, Q10 и Q14.
Q13 закрыт 2026-08-26 — [25](docs/25-station-storage.md), §9.

## Принятые решения (сборка на ESP32-P4)

Источники: [24](docs/24-main-build-p4.md) — перенос на P4, [33](docs/33-carrier-board.md) —
доп. платы, [25](docs/25-station-storage.md) — хранение станций.

| Узел | Решение |
|---|---|
| Платформа | плата **Waveshare ESP32-P4-WIFI6-Touch-LCD-5**, прошивка на ESP-IDF |
| Экран | штатный экран платы, 5″ DSI 720×1280, книжный, сенсорный |
| Список интернет-станций | Radio Browser как поисковик + своя база на карте + ручной ввод URL ([25](docs/25-station-storage.md)) |
| Эфирный тракт | модуль **RDA5807M** (RRD-102), I²C |
| Звук | ЦАП **PCM5102A** (I²S) → пассивный микшер с тюнером → 2 × **TPA3118** (HW-327, моно) → 2 динамика 4 Ом, стерео |
| Управление | 2 энкодера, кнопка питания, 8 пресетов и MODE через MCP23017, дублируется касанием |
| Питание | внешний блок **12 В / 5 А**, предохранитель T5A, защита от переполюсовки; 5 В на P4 через USB-C (чтобы заряжалась батарея платы), 12 В на усилители напрямую |
| Батарея | ставится в штатный разъём платы (2026-08-26, вопрос Q14) |

Открыто: корпус, проверка наличия вещания в УКВ OIRT на месте — см.
[06](docs/06-open-questions.md).

## Конфигурация (сборка на ESP32-P4)

Полная схема доп. плат — один лист в `hardware/kicad/carriers/`
([отчёт](hardware/kicad/carriers/README.md)); перечень деталей —
[35](docs/35-carrier-boards-parts.md).

```
        антенна
           │
   ┌───────┴────────┐   I²C    ┌────────────────────────┐
   │  RDA5807M      │◄────────►│  Waveshare ESP32-P4    │  экран 5″ 720×1280, тач,
   │  УКВ+FM, RDS   │          │  WIFI6-Touch-LCD-5     │  Wi-Fi ──► интернет
   └───────┬────────┘          │  (гребёнка J3, шлейф)  │◄── энкодеры, кнопки,
           │ L/R аналог        └───────────┬────────────┘    MCP23017 (пресеты, MODE)
           │                               │ I²S
           │                               ▼
           │                       ЦАП PCM5102A (стерео)
           │                               │ L/R аналог
           ▼                               ▼
   микшер на канал (эфир 1 к, интернет 10 к, подстроечник уровня)
                │ L                         │ R
                ▼                           ▼
     TPA3118 (HW-327) ──► динамик L   TPA3118 (HW-327) ──► динамик R

   Питание:  блок 12 В / 5 А ─► F1 T5A ─► защита ─┬─► усилители, 12 В
                                                  └─► DC-DC 12→5 В ─┬─► P4 по USB-C
                                                                    └─► LDO 3,3 В → тюнер
```

## Принципы, которых держимся

- **Из готовых модулей.** Ничего не разводим с нуля, пока модуль решает задачу.
- **Список станций живёт в приборе.** Внешний каталог нужен только в момент
  поиска, не при каждом включении.
- **Каждый шаг макета проверяем отдельно** и не ломаем предыдущий.
- **Что не проверено — помечено.** В документах указано, что взято из даташита,
  что из живого запроса с датой, а что требует проверки на макете.
