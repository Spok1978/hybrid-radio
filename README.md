# IP-Radio — приёмник УКВ/FM + интернет-радио

Проект приёмника с двумя режимами работы:

1. **Эфир** — УКВ OIRT (65,8–74 МГц) и FM CCIR (87,5–108 МГц): автопоиск,
   частота и название станции на экране, ручная настройка, пресеты.
2. **Интернет-радио** — подключение к Wi-Fi, поиск станций, воспроизведение,
   свой список станций.

Один цветной экран 5″/7″ на оба режима, экранное меню + кнопки, один
громкоговоритель, переключение режимов тумблером.

## Принятые решения (2026-08-17)

| Узел | Решение |
|---|---|
| Список интернет-станций | Radio Browser как поисковик + **своя локальная база** + ручной ввод URL |
| Эфирный тракт | модуль **RDA5807M** (оба диапазона регистром BAND, SEEK и RDS в чипе) |
| Платформа | **Raspberry Pi 3 Model B+** (1 ГБ, DSI, dual-band Wi-Fi); ESP32 отклонён |
| Экран | **Touch Display 2, 5″** ($40), сенсорный; 720×1280 → в ландшафте 1280×720 |
| Интерфейс | без браузера (PyQt5 / pygame поверх KMS), воспроизведение — MPD/mpv в фоне |
| Звук | стерео-ЦАП **PCM5102A** → пассивная сумма → УНЧ **TPA3118D2** от 12 В → один динамик 4 Ω, 10–15 Вт |
| Питание | внешний блок **12 В / 3 А**, гнездо 5,5×2,1; усилитель от 12 В напрямую, Pi через понижающий преобразователь |
| Выключение | корень **только для чтения**, данные пишутся атомарно → снятие питания безопасно; кнопка мягкого выключения снимает питание сама. **Батарея не нужна** |

Открыто: корпус, проверка наличия вещания в УКВ OIRT на месте, бюджет —
см. [06](docs/06-open-questions.md). Веб-интерфейс с телефона отклонён:
экран сенсорный, а интерфейс нативный, поэтому веб-слой стал бы вторым
интерфейсом. Для массового ввода станций — импорт `.m3u` с USB-флешки.

## Конфигурация

```
        антенна
           │
   ┌───────┴────────┐   I²C    ┌──────────────────┐     DSI      ┌────────────────┐
   │  RDA5807M      │◄────────►│  Raspberry Pi    │◄────────────►│ Touch Display 2│
   │  УКВ+FM, RDS   │          │  3B+ (1 ГБ)      │              │  5″, 720×1280  │
   └───────┬────────┘          │                  │              └────────────────┘
           │ L/R аналог        │                  │◄─── GPIO ──── кнопки,
           │                   │  Wi-Fi ──────────┼──► интернет   энкодер,
           │                   └────────┬─────────┘    (Radio      тумблер
           │                            │ I²S           Browser)
           │                            ▼
           │                    ЦАП PCM5102A (стерео)
           │                            │ L/R аналог
           ▼                            ▼
        суммирующий узел (4×10 к): эфир + интернет, L+R → моно
                        │  подстроечник уровня
                        ▼
              УНЧ TPA3118D2 (10–15 Вт / 4 Ω) ──► динамик 4 Ω


   Питание:  внешний блок 12 В / 3 А ──┬──► УНЧ напрямую от 12 В
                                       └──► buck 12→5,1 В ──┬─► Pi + дисплей
                                                            └─► LDO 3,3 В → тюнер
```

## Принципы, которых держимся

- **Из готовых модулей.** Ничего не разводим с нуля, пока модуль решает задачу.
- **Список станций живёт в приборе.** Внешний каталог нужен только в момент
  поиска, не при каждом включении.
- **Каждый шаг макета проверяем отдельно** и не ломаем предыдущий.
- **Что не проверено — помечено.** В документах указано, что взято из даташита,
  что из живого запроса с датой, а что требует проверки на макете.
