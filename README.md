# IP-Radio — приёмник УКВ/FM + интернет-радио

Проект приёмника с двумя режимами работы:

1. **Эфир** — УКВ OIRT (65,8–74 МГц) и FM CCIR (87,5–108 МГц): автопоиск,
   частота и название станции на экране, ручная настройка, пресеты.
2. **Интернет-радио** — подключение к Wi-Fi, поиск станций, воспроизведение,
   свой список станций.

Один цветной экран 5″/7″ на оба режима, экранное меню + кнопки, один
громкоговоритель, переключение режимов тумблером.

## Предлагаемая конфигурация (на обсуждении)

```
        антенна
           │
   ┌───────┴────────┐   I²C    ┌──────────────────┐   DSI/HDMI   ┌──────────┐
   │  RDA5807M      │◄────────►│  Raspberry Pi    │◄────────────►│ экран 7″ │
   │  УКВ+FM, RDS   │          │  4/5             │              └──────────┘
   └───────┬────────┘          │                  │◄─── GPIO ──── кнопки,
           │ аналог            │  Wi-Fi ──────────┼──► интернет   энкодер,
           │                   └────────┬─────────┘    (Radio      тумблер
           │                            │ I²S           Browser)
           ▼                            ▼
      суммирующий узел ────────────► ЦАП PCM5102A
           │                            │
           └────────────► УНЧ ◄─────────┘
                          │
                       динамик
```

Обоснования — в документах 02–05, решение не принято до закрытия Q1–Q4.

## Принципы, которых держимся

- **Из готовых модулей.** Ничего не разводим с нуля, пока модуль решает задачу.
- **Список станций живёт в приборе.** Внешний каталог нужен только в момент
  поиска, не при каждом включении.
- **Каждый шаг макета проверяем отдельно** и не ломаем предыдущий.
- **Что не проверено — помечено.** В документах указано, что взято из даташита,
  что из живого запроса с датой, а что требует проверки на макете.
