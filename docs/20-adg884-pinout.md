# 20. ADG884: соединения на макетке

Только сама микросхема и её обвязка. Наружу выведены шесть точек, к другим
узлам прибора пока ничего не подключается.

Рисунок: [adg884-breadboard.svg](adg884-breadboard.svg)

## Детали на плате

| Обозначение | Что |
|---|---|
| DA1 | ADG884 на переходнике MSOP-10 → DIP |
| R1 | резистор 100 кОм |
| R2 | резистор 100 кОм |
| R3 | резистор 10 кОм |
| R4 | резистор 10 кОм |
| C1 | конденсатор плёночный 2,2 мкФ |
| C2 | конденсатор плёночный 2,2 мкФ |
| C3 | конденсатор электролитический 10 мкФ |
| C4 | конденсатор плёночный 3,3 мкФ |
| C5 | конденсатор керамический 0,1 мкФ |

## Точки, выведенные наружу

| Точка | Назначение |
|---|---|
| X1 | вход A |
| X2 | вход B |
| X3 | выход |
| X4 | управление |
| X5 | +3,3 В |
| X6 | общий (GND) |

## Внутренние узлы

| Узел | Состав |
|---|---|
| IN-A | вывод 2 DA1, вывод 2 конденсатора C1, вывод 2 резистора R1 |
| IN-B | вывод 5 DA1, вывод 2 конденсатора C2, вывод 2 резистора R2 |
| BIAS | вывод 1 резистора R1, вывод 1 резистора R2, вывод 2 резистора R3, вывод 1 резистора R4, плюс конденсатора C3 |

| Вывод | Имя | Соединяем с |
|---|---|---|
| 1 | VDD | точка X5; вывод 1 конденсатора C5 |
| 2 | S1A | вывод 2 конденсатора C1; вывод 2 резистора R1 |
| 3 | D1 | вывод 1 конденсатора C4 |
| 4 | IN1 | точка X4; вывод 8 DA1 |
| 5 | S1B | вывод 2 конденсатора C2; вывод 2 резистора R2 |
| 6 | GND | точка X6 |
| 7 | S2B | не подключаем |
| 8 | IN2 | вывод 4 DA1 |
| 9 | D2 | не подключаем |

| Вывод | Соединяем с |
|---|---|
| 1 | точка X1 |

| Вывод | Соединяем с |
|---|---|
| 1 | точка X2 |

|---|---|
| 1 | вывод 1 резистора R2; вывод 2 резистора R3; вывод 1 резистора R4; плюс конденсатора C3 |

|---|---|
| 1 | вывод 1 резистора R1; вывод 2 резистора R3; вывод 1 резистора R4; плюс конденсатора C3 |

| 1 | точка X5 |

| 1 | выводы 1 резисторов R1 и R2; вывод 2 резистора R3; плюс конденсатора C3 |

| Вывод | Соединяем с |
|---|---|
| 1 | вывод 3 DA1 |
| 2 | точка X3 |

## C5 — керамический 0,1 мкФ

| Вывод | Соединяем с |
|---|---|
| 1 | вывод 1 DA1; точка X5 |
| 2 | точка X6 |

## Проверка собранного узла

1. Подать на X5 напряжение 3,3 В, на X6 — общий провод.
2. Измерить напряжение на узле BIAS относительно X6: должно быть 1,65 В ±0,1.
3. Измерить напряжение на выводе 2 DA1 и на выводе 5 DA1 относительно X6:
   на обоих должно быть 1,65 В ±0,1.
4. Подать на X4 ноль, затем 3,3 В. Напряжение на выводе 3 DA1 относительно
   X6 в обоих положениях должно оставаться 1,65 В ±0,1.
