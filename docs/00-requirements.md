# 00. Требования к приёмнику

Источник: постановка задачи от 2026-08-17. Здесь зафиксировано **что хотим**,
без выбора железа — выбор в документах 02–05.

## Общее

| № | Требование |
|---|------------|
| R1 | Два режима работы: **эфирный приёмник** (УКВ/FM) и **интернет-радио** |
| R2 | Переключение режимов — тумблером/переключателем (физическим) |
| R3 | Один общий цветной экран на оба режима, 5″ или 7″. Сенсор — не обязателен |
| R4 | Управление — экранное меню + кнопки |
| R4.1 | **Два способа управления одновременно: сенсорный экран и физические органы — энкодер и кнопки.** Прибор рассчитан в том числе на пожилых пользователей, которым крутить ручку и нажимать кнопку привычнее и проще, чем работать с сенсором. Гибкость управления — заявленная особенность прибора, а не запасной вариант (добавлено 2026-08-21) |
| R5 | Один громкоговоритель, работает в обоих режимах |
| R6 | Собирать по возможности из готовых модулей, соединяемых между собой |

## Режим 1 — эфирный приёмник

| № | Требование |
|---|------------|
| R1.1 | Приём диапазонов **УКВ** (OIRT, 65,8–74 МГц) и **FM** (CCIR, 87,5–108 МГц) |
| R1.2 | Автопоиск станций по диапазону |
| R1.3 | Отображение текущей частоты на экране |
| R1.4 | Отображение названия станции (это RDS/RDS-PS — см. [02](02-fm-frontend.md)) |
| R1.5 | Ручная перестройка по частоте с индикацией |
| R1.6 | Запоминание станций (пресеты) |
| R1.7 | Переключение между запомненными станциями — меню и кнопки |

## Режим 2 — интернет-радио

| № | Требование |
|---|------------|
| R2.1 | Поиск доступных сетей Wi-Fi |
| R2.2 | Подключение к выбранной сети, ввод пароля |
| R2.3 | Запоминание параметров сети (автоподключение при следующем включении) |
| R2.4 | Поиск интернет-радиостанций — **способ выбирается**, см. [01](01-station-directories.md) |
| R2.5 | Выбор станции из списка кнопками, запуск воспроизведения |
| R2.6 | Хранение списка станций локально |

## Что в требованиях НЕ сказано и надо решить

Вынесено в [06-open-questions.md](06-open-questions.md):
питание (сеть/аккумулятор), корпус, мощность звука, стерео или моно,
нужен ли Bluetooth/AUX, нужна ли запись эфира, нужен ли DAB+.
