# 21. Задание на поиск плат ESP32 с экраном

Чек-лист для отбора. Сначала отсекающие требования, затем балльная оценка.

## Отсекающие требования

Не выполняется хотя бы одно — плата не рассматривается.

| № | Требование | Почему |
|---|---|---|
| 1 | **PSRAM не менее 4 МБ** | буфер потока и рабочая память декодера; MiniWebRadio требует именно столько |
| 2 | **Wi-Fi** — свой или через сопроцессор | режим интернет-радио |
| 3 | **Цветной экран с подсветкой** | R3 |
| 4 | **Шина I²C, выведенная наружу** | тюнер RDA5807M управляется только по I²C |
| 5 | **Есть в продаже** | плата Waveshare на P4 отсутствовала на складе при проверке |

## Балльная оценка, всего 100

| Функция | Вес | Почему столько |
|---|---|---|
| **Кодек с аналоговым входом** (ES8311 или аналог, АЦП на входе) | **20** | выход тюнера заводится внутрь, микширование программное. Убирает целый узел: сумматор, аналоговый ключ, смещение |
| **Дисплей из списка, поддерживаемого MiniWebRadio** | **18** | SPI ILI9341, ILI9486, ILI9488, ST7796; RGB 800×480; DSI 1024×600. Иначе дисплейный порт писать самим |
| **Диагональ 5–7″** | **12** | требование R3. Заказчик считает меньший экран допустимым, поэтому не отсекающее |
| **Слот microSD** | **10** | файл списка станций |
| **Свободных GPIO не менее 8** | **10** | энкодеры, кнопки и тумблер без расширителя портов |
| **Разрешение не менее 400 000 точек** | **8** | список станций плюс крупная частота на одном экране |
| **Wi-Fi на том же кристалле**, без сопроцессора | **8** | у связки P4 + C6 есть сообщения о нестабильности |
| **Поддержка Arduino**, а не только ESP-IDF | **6** | скорость разработки |
| **Ёмкостный тач** | **5** | ввод пароля Wi-Fi |
| **Цена до 60 долларов** | **3** | |

## Что нам не нужно и баллов не даёт

Камера, датчик положения, микрофоны, Ethernet, RS485, реле, аккумулятор
с зарядкой, часы реального времени (есть свой DS3231), усилитель и динамик
на борту (есть свой TPA3118 на 10–15 Вт против типовых 3 Вт).

Эти позиции часто занимают половину описания платы и создают впечатление
богатой комплектации — на нашу задачу они не работают.

## Минусы трёх лучших

**Espressif ESP32-P4-Function-EV-Board, 86 баллов.** В комплекте за 55 долларов
идут плата, экран 7″ 1024×600 с ёмкостным тачем, камера 2 Мп и кабели.
На борту ES8311 с усилителем 3 Вт, микрофон, разъём динамика, слот microSD,
16 МБ флеш, Ethernet, два USB и **40-контактная гребёнка J1**.

- Wi-Fi не на кристалле, а через модуль ESP32-C6-MINI-1; у этой связки есть
  сообщения о нестабильности;
- разработка практически только в ESP-IDF, поддержка Arduino для P4 сырая —
  в обсуждениях у людей не заводится тот самый ES8311;
- это **отладочная плата, а не изделие**: камера, Ethernet, два USB и
  отладочный мост занимают место и нам не нужны;
- экран — отдельная панель на шлейфе, «моноблока» нет, крепление в корпус
  придётся придумывать;
- встроенный усилитель 3 Вт против наших 10–15 Вт.

**Waveshare ESP32-P4-WIFI6-Touch-LCD-4B, 56 баллов.**

- **нет в продаже** на момент проверки — отсекающее требование не выполнено;
- дисплей 720×720 не из списка MiniWebRadio, дисплейный порт писать самим;
- 4″, требование R3 не выполняется;
- форм-фактор настенной панели 86×86 мм под монтажную коробку;
- Wi-Fi через сопроцессор, только ESP-IDF.

**Espressif ESP32-S3-BOX-3, 40 баллов.**

- экран 2,4″ 320×240 — мало под список станций;
- **нет слота карты**, список станций пришлось бы держать во флеш-памяти,
  а MiniWebRadio ожидает карту;
- дисплей ILI9342C не из списка прошивки;
- 16 GPIO выведены через разъёмы Pmod, а не гребёнки 2,54 мм — на макетке
  неудобно;
- закрытый корпус голосового ассистента: выводить наружу тюнер и антенну
  неудобно.

## Что спрашивать в описании платы

1. Объём PSRAM цифрой, а не «стековая память».
2. Точное название микросхемы кодека и есть ли у неё **вход** АЦП.
3. Контроллер дисплея и разрешение — именно контроллер, а не «IPS 2,8″».
4. Сколько GPIO выведено на разъёмы и какие из них не заняты внутри платы.
5. Есть ли слот карты и по какому интерфейсу.
6. Wi-Fi на том же кристалле или через сопроцессор.
7. Заявлена ли поддержка Arduino или только ESP-IDF.
