# 30. Раскладка выводов: два готовых варианта

Составлено 2026-08-27, когда закрылись оба ограничения по выводам
([26](26-firmware-spec.md), §2.7). Здесь обе конфигурации расписаны
до конкретного вывода, чтобы решение по расширителю принималось
по готовым таблицам, а не по прикидкам.

## Исходные данные

**Свободно на гребёнке J3 — восемнадцать выводов:**

> GPIO3, 4, 5, 21, 22, 28, 29, 30, 31, 32, 34, 46, 47, 48, 49, 50, 51, 52

**Три жёстких ограничения:**

1. **Кнопка питания — только GPIO3, GPIO4 или GPIO5.** Будить из глубокого
   сна умеет лишь домен VDD_LP, то есть GPIO0…GPIO15; из свободных туда
   попадают ровно эти три.
2. **GPIO34 — strapping-вывод** (источник JTAG). Использовать можно, но
   уровень в момент сброса имеет значение, поэтому держим его последним
   в очереди.
3. **Тюнер и расширитель садятся на штатную шину I²C** — GPIO7 (SDA)
   и GPIO8 (SCL), она выведена на гребёнку, подтяжки 2,2 кОм к 3,3 В
   уже стоят на плате.

Все кнопки — на землю, подтяжка вверх включается внутренняя; внешних
резисторов не требуется.

---

## Вариант 1 — с расширителем портов, восемь кнопок

**На выводах гребёнки — двенадцать линий:**

| Назначение | Вывод | Примечание |
|---|---|---|
| Кнопка питания | **GPIO3** | LP-домен, будит из сна |
| Энкодер 1, канал A | GPIO21 | |
| Энкодер 1, канал B | GPIO22 | |
| Энкодер 1, кнопка (ОК) | GPIO28 | |
| Энкодер 2, канал A | GPIO29 | |
| Энкодер 2, канал B | GPIO30 | |
| Энкодер 2, кнопка (Mute) | GPIO31 | |
| Прерывание расширителя | GPIO32 | |
| I²S BCK | GPIO46 | к PCM5102A |
| I²S LRCK | GPIO47 | |
| I²S DIN | GPIO48 | |
| Приглушение TPA3118 (SD) | GPIO49 | см. примечание ниже |

**На расширителе MCP23017 (адрес 0x20) — девять линий из шестнадцати:**

| Назначение | Линия |
|---|---|
| Кнопки пресетов 1…8 | GPA0…GPA7 |
| Кнопка MODE | GPB0 |

**Остаётся свободным шесть выводов:** GPIO4, GPIO5, GPIO34, GPIO50,
GPIO51, GPIO52. Плюс семь незанятых линий расширителя.

**Почему приглушение усилителя не на расширителе.** Выводы MCP23017 после
включения питания находятся в высокоимпедансном состоянии, пока прошивка
их не настроит. Линия SD у TPA3118 в этот момент оказалась бы «висящей»,
и состояние усилителя было бы неопределённым в первые миллисекунды.
На своём выводе оно детерминировано. Если всё же уводить на расширитель —
нужен внешний резистор, подтягивающий SD к состоянию «выключено».

| Энкодер 2, кнопка | GPIO31 | |

| **Кнопка пресета 3** | **GPIO34** | **strapping-вывод**, см. ниже |

**Восемнадцать из восемнадцати. Свободного не остаётся ничего**, и одна
кнопка сидит на strapping-выводе: если её удерживать в момент включения,
изменится источник сигналов JTAG.

### Вариант 2-бис — пять кнопок

Если убрать шестую кнопку, GPIO34 освобождается и остаётся в резерве.
Итого семнадцать из восемнадцати, одна линия про запас. Это честнее,
чем вариант 2, и не требует занимать strapping-вывод.

## Сравнение

| | Вариант 1 | Вариант 2 | Вариант 2-бис |
|---|---|---|---|
| Кнопок пресетов | **8** | 6 | 5 |
| Занято выводов | 12 из 18 | **18 из 18** | 17 из 18 |
| Запас | 6 выводов + 7 линий расширителя | **нет** | 1 вывод |
| Strapping-вывод занят | нет | **да** | нет |
| Лишнее железо | MCP23017 и один резистор подтяжки | нет | нет |

Ничего не рекомендую сверх того, что уже сказано: выбор за заказчиком,
таблицы готовы под оба.

## Что в этих таблицах ещё не проверено

- **Точная нумерация контактов гребёнки.** Состав цепей прочитан надёжно,
  а привязка «цепь → номер контакта» снималась с картинки и двоилась.
  Перед пайкой сверить по схеме или прозвонить
  ([26](26-firmware-spec.md), §2.5).
- **Распределение I²S по контроллерам.** У ESP32-P4 их три, штатный кодек
  занимает один; какой именно — смотреть в BSP платы. Наши три линии
  вешаются на любой из оставшихся, маршрутизация через матрицу GPIO
  подтверждена.
- **Скорость реакции энкодеров** на выбранных выводах: домен VDD_IO_0
  и VDD_IO_4, обычные HP-выводы с прерываниями — ограничений быть
  не должно, но проверяется на макете.
