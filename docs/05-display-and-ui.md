# 05. Экран, органы управления, экранное меню

Требования R3 (один цветной экран 5″ или 7″ на оба режима, сенсор не обязателен)
и R4 (меню + кнопки).

## 1. Варианты экрана для платформы Raspberry Pi

| Вариант | Разрешение | Подключение | Замечания |
|---|---|---|---|
| **Raspberry Pi Touch Display 2, 7″** | 720×1280, IPS, ёмкостный тач (до 5 касаний) | DSI-шлейф + питание с GPIO | Панель **портретная**, для горизонтального вида поворачивается программно. Углы обзора до 85°, антиблик |
| Raspberry Pi Touch Display 2, 5″ | 720×1280 | то же | Та же панель меньшего размера |
| Оригинальный 7″ Touch Display (1-го поколения) | 800×480, ландшафт | DSI + питание | Проще по геометрии (сразу ландшафт), качество матрицы хуже |
| HDMI-панели 5″/7″ сторонних вендоров | 800×480 или 1024×600 | HDMI + USB (тач) + питание | Больше кабелей, зато ландшафт и часто дешевле |
| DSI 7″ 1024×600 (Waveshare и др.) | 1024×600 | DSI | Ландшафт и высокое разрешение; совместимость смотреть по конкретной модели и версии ОС |

Для приёмника **удобнее ландшафт**: слева список станций, справа крупная
частота/название. Портретную Touch Display 2 можно повернуть, но в корпусе
она встанет «книжкой» — это вопрос дизайна корпуса, не электроники.

**Решение от 2026-08-17: Touch Display 2, 5″, с сенсором** ($40).
После программного поворота в ландшафт рабочее поле — **1280×720**, этого
с запасом хватает на список станций слева и крупную частоту справа.
Три факта, которые надо держать в голове (проверено 2026-08-17 на сайте
Raspberry Pi):

- у 5″ и 7″ **одинаковое разрешение 720×1280**, разница только в физическом
  размере и цене — $40 против $60;
- **Raspberry Pi Zero series с Touch Display 2 несовместимы** (у Zero нет
  разъёма DSI) — это исключает Zero 2 W из вариантов, см. [08](08-cost-and-board-choice.md);
- для Pi 5 нужен шлейф 22-way → 15-way, для Pi 4 и старше — 15-way → 15-way.

### Уточнение 2026-08-18: где это вообще продаётся

Оригинальный **Touch Display 2 — официальный продукт Raspberry Pi** (артикул
5″ версии **SC1975**, 7″ — **SC1635**) и продаётся через авторизованных
продавцов: raspberrypi.com, PiShop, Adafruit (6408), The Pi Hut, Vilros,
Micro Center, Kubii. **На AliExpress его нет.**

Что есть на AliExpress вместо него — панели Waveshare и их копии. Подходят
две, обе с 15-контактным DSI и заявленной поддержкой Pi 3B+:

### Пересмотр 2026-08-21: решает не размер, а наличие мейнлайн-оверлея

Главный критерий выбора сторонней панели — **есть ли она в штатном оверлее
`vc4-kms-dsi-waveshare-panel`**. Если есть, драйвер производителя не нужен и
обновление ОС ничего не ломает. Если нет — панель живёт на вендорском оверлее
со всеми вытекающими.

Проверено по официальному списку оверлеев Raspberry Pi (ветки ядра rpi-6.6.y,
rpi-6.12.y и rpi-6.17.y, 2026-08-21). Параметры `vc4-kms-dsi-waveshare-panel`:

```
2_8_inch    2.8"  480x640      7_0_inchC   7.0" C 1024x600
3_4_inch    3.4"  800x800      7_0_inchH   7.0" H 1280x720
4_0_inch    4.0"  480x800      7_9_inch    7.9"  400x1280
4_0_inchC   4.0"  720x720      8_0_inch    8.0"  1280x800
5_0_inch    5.0"  720x1280     10_1_inch  10.1"  1280x800
6_25_inch   6.25" 720x1560     13_3_inch  13.3"  1920x1080
```

| Модель | Разрешение | Ориентация | Мейнлайн-оверлей |
|---|---|---|---|
| **Waveshare 7inch DSI LCD (C)** | **1024×600** | **ландшафт** | **есть: `7_0_inchC`** |
| Waveshare 5inch DSI LCD (C) | 1024×600 | ландшафт | **нет** — `5_0_inchC` в списке отсутствует |
| Waveshare 5″ 720×1280 | 720×1280 | портрет | есть: `5_0_inch`, но нужен поворот |

**Вывод: рекомендация меняется с 5″ (C) на 7inch DSI LCD (C).** Требование R3
допускает и 5″, и 7″, а 7″ (C) даёт разом ландшафтные 1024×600 и штатную
поддержку без вендорского драйвера. 5″ (C) остаётся вариантом, только если
7″ не влезает в корпус — и тогда риск драйвера принимается осознанно.

Полезное из того же списка параметров: у оверлея есть ключ
`i2c1  Use i2c-1 with jumper wires from GPIOs 2&3`. По умолчанию тачскрин
сидит **не** на GPIO2/3, а на шине i2c_csi_dsi, идущей по шлейфу — то есть
с нашим тюнером на i2c-1 он не конфликтует. **Этот ключ включать нельзя:**
он посадит тач ровно на те выводы, где висит тюнер.

Питание панели: по оценкам 5″ 800×480 берёт ~250 мА, 7″ (C) — ~500 мА.
Уточнить в карточке, идёт ли питание по шлейфу DSI (тогда ток ложится на
шину 3,3 В самой Pi и его надо померить) или отдельным проводом с GPIO.

**Чего покупать нельзя:** версию **DPI** (у Waveshare она называется
«5inch DPI LCD» / «5inch LCD for Pi»). Она подключается к колодке GPIO и
занимает почти все выводы, а у нас там I²C тюнера, кнопки, энкодеры, тумблер
режима и линия приглушения усилителя.

Расчёт интерфейса ведём **на 1024×600**: при 800×480 та же раскладка
останется рабочей, просто в списке станций поместится меньше строк.

Для платформы ESP32 набор другой: плата «ESP32-S3 + 7″ RGB 800×480 + тач»
одним куском. У проекта MiniWebRadio есть прямое предупреждение: плата
**CrowPanel ESP32-P4 7.0 V1.0 (SKU DHE04107D) не работает из-за ошибки
проектирования платы** — при закупке этот момент проверить.

## 2. Органы управления

Минимальный комплект, который закрывает R4 без тача:

| Орган | Функция в режиме 1 (эфир) | Функция в режиме 2 (интернет) |
|---|---|---|
| Энкодер с нажатием | вращение — перестройка частоты / выбор пункта; нажатие — ОК | прокрутка списка станций; нажатие — играть |
| Кнопка ◄ | предыдущий пресет | предыдущая станция |
| Кнопка ► | следующий пресет | следующая станция |
| Кнопка SEEK / поиск | автопоиск вверх (долгое — вниз) | поиск станций в каталоге |
| Кнопка MEM / память | запомнить текущую станцию | добавить в избранное |
| Кнопка MENU / назад | вход в меню / возврат | то же |
| Тумблер режима | — | — (читается как вход, см. [03](03-controller-platform.md)) |

Энкодер лучше кнопок «частота +/−»: перестройка по 1785 шагам сетки 50 кГц
кнопками невыносима. Громкость — либо второй энкодер, либо кнопки, либо
пункт меню; аналоговый потенциометр не нужен, так как громкость всё равно
регулируется программно в обоих режимах (у тюнера регистр громкости, у
вычислителя — микшер).

## 3. Структура экранного меню (черновик)

```
ГЛАВНЫЙ ЭКРАН (зависит от режима)

  Режим 1 — ЭФИР                        Режим 2 — ИНТЕРНЕТ
  ┌────────────────────────────┐        ┌────────────────────────────┐
  │  102.50 МГц      УКВ/FM    │        │  Radio Record          ▶   │
  │  ██████░░░ уровень         │        │  Artist — Track            │
  │  RDS:  RETRO FM            │        │  MP3 128 kbps   буфер ███  │
  │  ───────────────────────── │        │  ───────────────────────── │
  │  P1 P2 [P3] P4 P5 P6       │        │  ▸ Радио 1                 │
  │                            │        │    Джаз FM                 │
  │  ◄ ►  пресет   SEEK  MEM   │        │    Nightwave Plaza         │
  └────────────────────────────┘        └────────────────────────────┘

МЕНЮ (общее)
  ├── Станции
  │   ├── Пресеты эфира        (список, переименовать, удалить, порядок)
  │   └── Станции интернет     (список, избранное, удалить)
  ├── Поиск
  │   ├── Автопоиск по диапазону   → результат списком, отметить нужные
  │   ├── Ручная настройка          → шаг сетки, диапазон УКВ/FM
  │   └── Поиск в интернете         → по стране / жанру / названию → добавить
  ├── Сеть
  │   ├── Список сетей Wi-Fi   → выбрать → ввести пароль (экранная клавиатура)
  │   ├── Сохранённые сети
  │   └── Состояние: IP, уровень сигнала
  └── Настройки
      ├── Громкость, тембр
      ├── Яркость экрана, ночной режим
      ├── Диапазон по умолчанию, единицы
      └── О приборе / версия / журнал
```

Замечание по вводу пароля Wi-Fi: без сенсорного экрана экранная клавиатура
управляется энкодером — это терпимо один раз при настройке, но неприятно.
**Вопрос снят выбором сенсорного экрана** (решение от 2026-08-17): пароль
набирается пальцем. Запасной вариант на крайний случай — воткнуть
USB-клавиатуру, у Pi 3B+ четыре порта.

Веб-интерфейс с телефона рассматривался как обход этой проблемы и
**отклонён** — см. [06-open-questions.md](06-open-questions.md), Q9.
Для массового наполнения списка станций вместо него делаем импорт
`.m3u`/`.pls` с USB-флешки.
